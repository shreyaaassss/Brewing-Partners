# Brewing Partners

Landing page and menu for Brewing Partners, a neighbourhood coffee house.

Static HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to view it.

- `index.html` — landing page
- `menu.html` — full menu, one tab per category
- `css/styles.css` — design tokens and site styles
- `css/menu.css` — menu page styles
- `js/main.js` — nav, scroll reveals, underline animation, menu tabs, hero video
- `assets/` — logo, photos and the hero video

The design system is adapted from the Kindsight style reference (`DESIGN (6).md`, `tokens (6).json`).
